# Security and privacy notes

This public copy was prepared without API keys, passwords, credentials, private keys, `.env` files, raw Git metadata, virtual environments, checkpoints, or local environment directories.

The raw tweet dataset is excluded intentionally. Download it locally according to its source terms. Generated processed data, predictions, arrays, model checkpoints, notebook checkpoints, and result directories are ignored by the root `.gitignore` unless selected evidence files are explicitly staged.

Before publishing, run a secret scanner over the complete repository and inspect the Git diff. Do not add cloud credentials, private dataset exports, local absolute paths, or copied academic reports.
